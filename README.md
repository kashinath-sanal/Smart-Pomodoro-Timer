# Smart Pomodoro Timer 🍅

A simple Pomodoro Timer built with Python and Tkinter to help manage focused work sessions and breaks.

## Features

- Start and pause the timer
- Work and break sessions
- Customizable work and break durations
- Task name support
- Session tracking
- Simple graphical user interface

## Built With

- Python
- Tkinter
